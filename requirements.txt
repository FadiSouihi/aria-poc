# ARIA-POC runtime dependencies (cross-platform: Windows, Linux, Jetson).
#
#   Windows : .\setup.ps1        Linux / Jetson : ./setup.sh
#
# PyTorch is NOT listed here on purpose: it does not come from PyPI for CUDA, and
# on Jetson it comes from NVIDIA's own index instead. The setup scripts install
# the right build for the machine; manually it is:
#
#   x86-64 + NVIDIA GPU : pip install torch torchvision --index-url https://download.pytorch.org/whl/cu126
#   x86-64 CPU only     : pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
#   Jetson (JetPack 6.1): pip install torch torchvision --index-url https://developer.download.nvidia.com/compute/redist/jp/v61/pytorch
#
# NOTE - torchaudio is deliberately NOT a dependency:
#   * the CUDA torch builds we use have no matching torchaudio, and adding one
#     downgrades torch and breaks torchvision (`operator torchvision::nms does
#     not exist`);
#   * everything we needed from it is implemented in-repo instead:
#       - Silero VAD v5 runs directly on weights/silero_vad.onnx (onnxruntime);
#       - Smart Turn's whisper log-mel is computed in numpy (aria/audio/turn.py).
#   Do not add the `silero-vad` package either: it hard-imports torchaudio.
#
# NOTE - voice-prints use the raw-waveform WavLM ONNX model, not SpeechBrain:
#   speechbrain hard-imports torchaudio, and `resemblyzer` needs `webrtcvad`,
#   which requires MSVC build tools on Windows. Both stay optional extras
#   (requirements-dev.txt).
